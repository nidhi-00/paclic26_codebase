# Paper source note

PACLIC 40 requires the official ACL 2026 two-column style. The old repository used a generic `geometry` setup; that has been removed.

1. Download the official ACL 2026 style files.
2. Place `acl.sty` and `acl_natbib.bst` beside `main.tex`.
3. Transfer the real manuscript text into this shell.
4. Populate numerical results only after the corrected full pipeline finishes.
5. Run ACL Pubcheck before submission.

The uploaded repository did not contain the manuscript's complete LaTeX source, so this folder provides a compliant shell and reporting hooks rather than pretending to reconstruct the full paper from the PDF.
